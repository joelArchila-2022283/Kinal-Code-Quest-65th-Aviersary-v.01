> DATOS PRIMITIVOS Y CONSTANTES

En Java, las variables guardan valores puros en la memoria Stack (como int o double). El uso de la palabra clave final congela el valor convirtiéndolo en una constante inmutable del sistema.

> TOMA DE DECISIONES DE FLUJO

El flujo básico se ramifica mediante la compuerta lógica condicional if-else o a través de bloques indexados de tipo switch para optimizar bytecode.

> ITERACIÓN Y REPETICIÓN

Bucle for (ciclos fijos con contador), while (evaluación al inicio) y el ciclo do-while (evalúa al final, asegurando al menos una ejecución obligatoria).

> ESTRUCTURAS DINÁMICAS DE DATOS

Manejo de memoria dinámica: ArrayList ofrece redimensionamiento elástico automático. HashMap asocia llaves hashing únicas con sus respectivos objetos logrando búsquedas en complejidad óptima O(1).

> MODULARIZACIÓN Y FIRMAS DE RETORNO

Bloques lógicos reutilizables. Requieren definir en su firma el tipo de dato explícito a regresar con la cláusula return o marcarse como void si son rutinas directas sin retorno.

> PILARES POO: CLASES, HERENCIA Y ACCESOS

Los objetos nacen en la memoria Heap usando el operador new. Mediante extends una subclase hereda comportamientos del padre. Los modificadores (como private) protegen los datos internos (Encapsulamiento).

> COMPUERTAS DE SEGURIDAD (TRY-CATCH-FINALLY)

Las excepciones controlan fallos en tiempo de ejecución. El código inestable se encierra en un try, el error se procesa en el catch, y los flujos abiertos de memoria se clausuran limpiamente dentro del bloque finally.

> ACCESO A DATOS PERSISTENTES (JDBC)

Para transferir registros del software a la base de datos MySQL, se levantan conexiones a través de drivers JDBC. Las consultas parametrizadas se orquestan mediante objetos de tipo PreparedStatement para blindar la base de datos.
