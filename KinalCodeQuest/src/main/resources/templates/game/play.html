> DATOS PRIMITIVOS Y CONSTANTES

En Java, las variables se clasifican en tipos primitivos y objetos de referencia. Los tipos primitivos (como int, double, boolean) guardan el valor puro en la memoria Stack.

Para fijar un valor inalterable en el sistema y mapearlo como constante, se debe anteponer la palabra reservada final. Una vez asignado, el compilador bloqueará cualquier intento de reescritura.

> TOMA DE DECISIONES DE FLUJO

La compuerta lógica básica es el bloque if-else. Evalúa una expresión booleana para bifurcar el comportamiento del sistema informático.

Para evaluar múltiples opciones basadas en una única variable limpia, la alternativa estructurada es el bloque switch, el cual optimiza los saltos de instrucción en bytecode.

> ITERACIÓN Y REPETICIÓN

Java cuenta con tres herramientas de iteración nativas:

  • for: Ideal cuando la cantidad de ciclos es conocida mediante un contador.
  • while: Evalúa la expresión al inicio; si es falsa desde el principio, el bloque jamás se ejecuta.
  • do-while: Evalúa la condición al final, asegurando que el código se ejecute al menos una vez de forma obligatoria.
> ESTRUCTURAS DINÁMICAS DE DATOS

A diferencia de los arreglos estáticos, el framework de colecciones maneja memoria dinámica estructurada:

  • ArrayList: Crece o se reduce dinámicamente según se requiera con los métodos nativos .add() y .remove().
  • HashMap: Guarda pares clave-valor indexados, optimizando la búsqueda directa de elementos en un tiempo computacional constante O(1).
> MODULARIZACIÓN Y FIRMAS DE RETORNO

Los métodos empaquetan bloques de lógica reutilizables en el firmware. Es obligatorio declarar el tipo de datos preciso que regresará el flujo mediante la palabra reservada return (como int, String o boolean).

Si la función ejecuta una rutina directa sin retornar ningún valor al flujo del sistema, se declara con la palabra clave void.
